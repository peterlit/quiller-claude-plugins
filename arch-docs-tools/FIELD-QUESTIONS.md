## Settled decisions — report only NEW evidence

Each of these was decided deliberately. A report that re-raises one without
new evidence costs a proposal slot and is declined. If your run produced
evidence that contradicts one, that IS worth a defect — cite the decision's
id.

- **s-two-diagram-classes** — High-level sequence and flow diagrams speak plain-English roles and actions with no commands, paths or quoted aliases; detailed data-model and wiring diagrams use precise identifiers.
- **s-lint-is-heuristic** — `mermaid_lint.py` is a heuristic linter, not an embedded renderer. It catches the common generation errors; a full render check was not adopted.
- **s-coverage-is-advisory** — `coverage_check.py` always exits 0 and the orchestrator judges the gaps. Residual gaps go in a "Not covered" appendix, never a failing check.
- **s-documenter-inherits** — The documenter uses `model: inherit`. There is no adversarial pairing here, so no pinned second model.
- **s-manifests-are-claims** — The overview agent treats the detail agents' MANIFEST blocks as claims to verify, not as facts.
- **s-regenerate-not-hand-edit** — Docs cite paths and line numbers, so they age with the code: re-dispatch the documenters after a release that moves code rather than hand-editing.
